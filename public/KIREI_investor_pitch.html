02 — ソリューション

「鏡の代替」として設計された
AIビューティーミラー

KIREIは「歯科アプリ」でも「スキンケアアプリ」でもない。スマートフォンを「毎朝触れる鏡」そのものに置き換えることで、リテンション問題を構造的に解決する。

1
ミラー画面
カメラを向けると自動で肌分析。トーン・毛穴・くすみをリアルタイム評価。
2
デンタルチェック
口元を映すと歯茎の色味・着色・歯並びを自動スコアリング。
3
統合結果
肌スコア＋デンタルスコアを表示。ケア提案・クリニック送客・コンテンツ誘導。
✨

マスコット「キラリ」

鏡の妖精キャラクターが毎日のチェックをナビゲート。継続使用を感情的に後押しする。

📊

スコア履歴

日々のチェックが積み重なり「変化がわかる」体験に。ケア継続のモチベーションを生む。

🔔

定期リマインダー

朝のルーティンにプッシュ通知で組み込み。習慣化レイヤーをアプリ側で担保する。

03 — ビジネスモデル

三層収益構造

無料ユーザー獲得 → 高単価送客 → データマネタイズという三層設計。Cocomiプラットフォームと共通するアーキテクチャを採用し、開発ノウハウを流用する。

Layer 1

無料ビューティー / ヘルスチェック

AIスコアリング・キラリのコメント・履歴閲覧は完全無料。ユーザー獲得コストを最小化し、習慣化をまず確立する。

Layer 2

提携歯科送客 ／ ケアグッズ EC（KIREI SELECT）

デンタルスコアから提携クリニックへの予約誘導。自費診療（ホワイトニング・矯正）の客単価は高く、送客手数料が主要収益源となる。並行してケアグッズのアフィリエイト・直販も展開。

Layer 3

匿名化データ分析・提供（将来フェーズ）

蓄積された口腔・肌データの匿名化集計値を、製薬・化粧品・医療機器メーカーへ提供。個人情報保護法・倫理ガイドラインに準拠した設計を初期から実装。

最初の提携先である山田兄弟歯科グループは自費診療3拠点を持ち、
ホワイトニング・矯正・インプラントの単価が高い。送客モデルの初期検証に最適。

08 — 技術

医療表現に準拠した
設計思想

KIREIは「診断」でなく「気づき」を提供するツールとして設計されている。体重計が医療機器でないのと同じポジションを明確に定義することで、薬機法・医師法上のリスクを回避する。

🔬

AI分析の現在地

HSV/RGB色空間での肌色分析と照明正規化は技術POCで実証済み。MediaPipe FaceLandmarkerによる顔ランドマーク検出で精度向上を図る（仕様策定済み）。

WebRTC MediaPipe Canvas API
⚖️

医療表現ガイドライン

「診断」「治療」「病気」等の医療用語は全面禁止。「チェック」「スコア」「ケアのヒント」「歯科医に相談」の表現に統一し、結果画面に必ず免責事項を表示。

薬機法対応 医師法対応
📲

クロスプラットフォーム戦略

Phase 1はCapacitorでReact JsをiOS/Androidにラップ。Phase 3でiOSネイティブ（Swift/SwiftUI）へ移行し、TrueDepth Camera等の精密センサーを活用。
